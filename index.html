How colors are calculated

Calorie density (CD) = calories ÷ grams (or mL).

Type Green Yellow Orange
Solid food< 1.01.0–2.4> 2.4
Drink< 0.40.4–0.5> 0.5
Soup / sauce / spread, canned fruit & beans< 0.50.5–1.0> 1.0
  • Water, plain tea/coffee and spices: no color.
  • Whole grains: green if CD < 2.4, otherwise yellow.
  • Dairy: nonfat green, low-fat yellow, whole/full-fat orange.
  • Diet or artificially sweetened drinks: always yellow.
  • Alcohol and sugary soda: moved up one color.

These rules come from Noom's public help article (How Noom's Food Color System Works). Noom's experts hand-adjust some foods, so a result here may sometimes differ from the app. Food type and flags are guessed from the name and category, so check them and use "Adjust" if one is wrong. USDA values are per 100 g; for drinks, 100 g is treated as about 100 mL.

This is an independent personal tool. It is not made, endorsed or reviewed by Noom. Food data: USDA FoodData Central (public domain; brand-name data comes from manufacturers) and, for barcodes, Open Food Facts (ODbL, user-contributed). Check brand data against the package label.
